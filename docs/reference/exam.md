# Dummy data set for Cochran's Q test

A dataset containing information about results of three exams.

## Usage

``` r
exam
```

## Format

A data frame with 15 rows and 3 variables:

- exam1:

  result of exam1

- exam2:

  result of exam2

- exam3:

  result of exam3
